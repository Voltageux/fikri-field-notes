# Fikri Radiyan — Field Notes: Public Release v0.4

A lightweight public website generated by `build.py` from Markdown. No credentials or private research files are included.

Public journals:
- `/game/` — Crust & Crime development
- `/water/` — Water engineering experiments
- `/career/` — AI-assisted career journal

## Before publishing

Review every article and the About page. Only publish details you are happy to put on the public internet. The three introductions remain unchanged from v0.3, so you can rewrite them in your own casual diary voice first if desired. Readers can view source content because the website repository will be public.

## Host using GitHub + Cloudflare Pages (recommended)

1. Create a NEW GitHub repository named `fikri-field-notes` (public). Do not add your other research folders.
2. Extract this release ZIP and upload its **contents** to the new repository on the `main` branch (via GitHub Desktop or Git). Do not upload the ZIP as one file.
3. At https://dash.cloudflare.com go to Workers & Pages -> Create -> Pages -> Connect to Git and select your new repository.
4. Configure:
    - Framework preset: None / No framework
    - Production branch: `main`
    - Build command: `python3 -m pip install -r requirements.txt && python3 build.py`
    - Build output directory: `dist`
    - Root directory: repository root
5. Deploy. Cloudflare supplies `CF_PAGES_URL`, which this builder uses for absolute RSS links, sitemap links and canonical URLs. The first live link will be a Cloudflare-hosted `.pages.dev` URL.
6. Open the live link and test Home, Game, Water, Career, About, articles, stylesheet, and `/rss.xml`.
7. If you later use a custom domain, set `PUBLIC_SITE_URL` as a production environment variable in Cloudflare Pages to `https://your-real-domain.com`, then redeploy. This updates canonical, sitemap and RSS links.

**Important:** Public GitHub repositories and live Cloudflare pages are genuinely public. No passwords or login restrictions are in place. Blog comments are not active until Giscus is configured.

### Updating journal entries

Create a Markdown file at `content/game/`, `content/water/`, or `content/career/`, following the existing article structure. Commit and push to `main`; Cloudflare deploys the site automatically. Review the live result.

### Local preview on Windows

In the extracted folder, run:

```powershell
python -m pip install -r requirements.txt
python build.py
python -m http.server 8000 --directory dist
```

Go to http://localhost:8000. If an old local server is running, stop it with Ctrl+C first.

### Getting the code onto GitHub using Git (alternative to GitHub Desktop)

After creating the empty repository on GitHub, in the extracted project folder:

```powershell
git init -b main
git add .
git commit -m "Launch Field Notes public website"
git remote add origin https://github.com/YOUR-USERNAME/fikri-field-notes.git
git push -u origin main
```

Use the repository URL shown on GitHub. GitHub may ask you to authenticate. Never paste your account password or tokens into chat.
